# Мои рецепты — редакция 1.3.2

20 рецептов, отдельные детские завтраки, заметки и оценки семьи. Рабочий сайт — существующее веб-приложение Google Apps Script. Запуск локального сервера и GitHub-токен для ежедневного использования не нужны.

## Где что находится

- HTML, `breakfast.css`, `recipe-core.js`, `breakfast.js`, `portions.js` — страницы, оформление и расчёты.
- `recipes_data.json`, `nutrition_basis.json`, `nutrition_summary.json` — данные рецептов и расчётная база. HTML также содержит соответствующий JSON для автономного расчёта без fetch. При изменении состава нужно синхронно обновлять JSON, встроенные данные, статический текст страниц и сводки.
- `apps-script/Code.gs` — сервер, преобразование страниц, заметки, оценки и версионный кэш.
- Google Drive → существующая папка «Заметки» — личные записи. Их нет в этом репозитории.
- `tests/` — локальные проверки. Google-сервисы в тестах имитируются, рабочий Диск не затрагивается.

## Обновление с редакции 1.2 (до 1.3.1)

1. Сохрани копию текущего `Code.gs` из Google Apps Script. Репозиторий также можно скачать ZIP-архивом перед заменой.
2. Обнови файлы репозитория из пакета, сохранив структуру папок. `apps-script/Code.gs` должен остаться внутри `apps-script`, не в корне.
3. В существующем Google Apps Script полностью замени код содержимым `apps-script/Code.gs` и сохрани.
4. «Начать развёртывание» → «Управление развёртываниями» → активное развёртывание → карандаш → «Новая версия» → «Начать развёртывание». Не создавай другой проект и новое развёртывание. Настройки доступа не меняй.
5. Открой прежнюю ссылку сайта, нажми «Обновить рецепты». После успеха — «Открыть обновлённую коллекцию →».

Соблюдай порядок: новый `recipe-core.js` добавлен в импортируемые ресурсы серверного кода. Старую кнопку импорта до обновления серверного кода лучше не нажимать. Повторный ручной запуск `setupRecipes` не нужен.

## Оценки и заметки

Оценки Андрея (`andrey`), Регины (`regina`), Ярослава (`yaroslav`) — целые числа 1–5; отсутствие — `null`, не ноль. Нажатие звезды сохраняет оценку сразу. «Сбросить» удаляет только оценку выбранного человека. Текст заметки сохраняется отдельной кнопкой.

На Диске используется прежний файл `<рецепт>.json`. Поля `text`, `revision` и `updatedAt` совместимы со старой схемой. Добавлены `schemaVersion: 2`, `ratings`, `ratingRevisions`, `ratingsUpdatedAt`. Запись заметки не перезаписывает оценки; запись оценки не меняет текст. Для каждого человека своя ревизия, для текста — своя. Конфликт на двух устройствах возвращает ошибку, а не молча затирает данные.

Пустой текст не показывается в «Все заметки». Файл остаётся, если есть хотя бы одна оценка. Если текст и все оценки пусты, файл перемещается в корзину. Обновление сайта не затрагивает папку личных записей.

## Целые яйца и порции

Видимые ингредиенты, шаги и сводный список используют яйца в штуках. Внутренняя расчётная масса — условные 55 г на яйцо; это не стандарт размера и не требование взвешивать яйца.

В рецептах с яйцами различаются выбранные порции и приготовляемая партия. Пропорции всех компонентов сохраняются. Для хачапури учитывается разделение целых яиц между основой и верхом; минимальная партия — 2 порции (2 яйца в основу, 1 наверх). Для митболов — 4 порции на 1 яйцо. Остаток и его энергия показаны отдельно.

Блины: общий замес округляется вверх до целых яиц, по фактическому замеру примерно по 4 блина на яйцо (12 блинов из 3 яиц при прежнем способе приготовления). Молоко, мука, масло, сахар и соль увеличиваются вместе. Начинка и соусы рассчитываются только на выбранные порции. Лишние блины не включаются в КБЖУ выбранной еды; их КБЖУ показаны отдельно. При другом фактическом выходе используй доли готовой массы, указанные на странице.

## Детские соусы

Соусы включены в состав и КБЖУ восьми несладких детских завтраков: тортилья, бутерброд с котлетой, куриные оладьи, блины, рёшти, котлетки из индейки, тост и картофельно-куриные лепёшки. В тортилье перец исключён только для ребёнка.

Базовые соусы не содержат молока, йогурта, сливок или сыра. Блины по-прежнему содержат обычное молоко и яйцо; исходное предупреждение и ограничения сохранены. Необязательный сыр не включён в базовые КБЖУ. Бульон больше не используется. Пять куриных детских соусов готовятся с холодной водой, крахмалом и соками курицы на той же сковороде, без предварительных заготовок. Три овощных соуса готовятся из свежих моркови/кабачка и воды параллельно основному блюду. Соусы не проверены фактической готовкой.

## Кэш

CSS и JS встраиваются сервером в HTML. Ключ кэша содержит версию исходников и `RECIPES_APP_BUILD`. Кнопка обновления меняет версию после импорта. Списки личных записей используют отдельную версию: поздний ответ старого запроса не возвращает устаревший список в действующий кэш.

Если сервер сообщает об обновлённой версии уже открытой странице, показывается ссылка на свежую страницу без автоматического ухода с несохранённой заметки. Изменение `Code.gs` в GitHub само по себе не публикует сервер: нужна новая версия существующего развёртывания.

## Локальные проверки для разработчика

Из корня проекта с установленным Node.js:

```sh
node tests/core.test.cjs
node tests/backend.test.cjs
```

Браузерная проверка: запусти `node tests/preview-server.cjs`, затем `python tests/browser.test.py`. Требуются Python Playwright и установленный Chromium; путь к браузеру задаётся переменной `CHROMIUM_PATH` (по умолчанию `/usr/bin/chromium`). Тесты используют локальную имитацию Drive/RPC, не реальный Google-аккаунт. Файлы снимков создаются в `test-output/`.

Старые `github-notes.js` и `notes.html` сохранены как прежние исходники; рабочее веб-приложение их не использует. Не вставляй токены в публичный репозиторий.

- https://developers.google.com/apps-script/reference/cache/cache

## Обновление с редакции 1.3 до 1.3.1

Это обновление меняет только содержимое рецептов, документацию и расчётные данные. `apps-script/Code.gs` и `recipe-core.js` остаются прежними. Достаточно загрузить изменённые файлы на GitHub и нажать «Обновить рецепты» на уже работающем сайте. Публиковать новую версию Apps Script не требуется. Ни оценки, ни заметки не изменяются. Для начальной установки со старой редакции (1.2 и раньше) смотри полную инструкцию выше.

## Уточнение выхода блинов 1.3.2

Практический результат пользователя: тесто на 3 яйцах, 600 мл обычного молока, 150 г муки, 41,4 г масла, 30 г сахара и 1,5 г соли дало 12 блинов, не 18. Модель теперь ожидает 4 блина на яйцо. Рецепт сохраняет 3 блина на взрослую порцию и 2 на детскую, поэтому для тех же порций потребуется больше теста; начинку не увеличиваем. КБЖУ выбранных блинов пересчитаны, остаток пустых блинов отдельно. Фактический выход зависит от толщины и диаметра сковороды. `Code.gs` не менялся — обнови GitHub, затем нажми «Обновить рецепты» на сайте.
